# 택배 도착 즉시 음성 알림 — MVP 시연 앱

특허 제10-2004487호 「택배 물품 배송 알림 방법」의 핵심 흐름을 통신사·배송 파트너 앞에서 **실제 스마트폰으로 시연**하기 위한 최소 기능 프로토타입입니다.

```
[배송원 단말 식별] → [송장 바코드/QR 스캔] → [수령인 확인] → (원클릭) 배송 완료 & 음성 발송 → [전달 상태·지연시간·로그]
```

---

## 1. 기술 스택 제안

| 구분 | 선택 | 이유 |
|---|---|---|
| 모바일 | **React Native + Expo (SDK 58)** | 빌드 없이 **Expo Go 앱으로 QR만 찍으면 실기기 실행**. 카메라·TTS·햅틱·기기 ID 모듈이 모두 Expo Go에 포함되어 있어 네이티브 빌드가 필요 없음 |
| 바코드 | `expo-camera`의 `CameraView` (`onBarcodeScanned`) | `expo-barcode-scanner`는 SDK 51에서 제거됨. QR / Code128 / Code39 / EAN / PDF417 / DataMatrix 지원 |
| 음성 | `expo-speech` (기기 내장 한국어 TTS) | 통신사 음성망 연동 전 단계에서 "고객이 듣게 될 음성"을 현장에서 바로 재생 |
| 단말 식별 | `expo-application` (Android ID / iOS IDFV) | 배송원 번호 + PIN + 기기 고유 ID 바인딩 |
| 로컬 저장 | `@react-native-async-storage/async-storage` | 세션·발송 로그 보관 |
| 백엔드(선택) | **Node.js 단일 파일 서버** (`server/index.js`, 의존성 0) | 모의 교환기 모드 기본. 환경변수만 넣으면 **Twilio Programmable Voice로 실제 전화 발신** (`<Say language="ko-KR">`) |

### 상용화 단계 백엔드 구성 (참고)

```
배송원 앱 ──HTTPS──▶ 알림 API (Node/NestJS 등) ──▶ 통화 오케스트레이터
                         │                          ├─ 통신사 음성 API (SKT/KT/LGU+ 기업 음성 발신, 050 안심번호)
                         │                          ├─ 또는 CPaaS (Twilio / Vonage / NHN Cloud Notification / 카카오 i 커넥트)
                         │                          └─ 미응답 시 MMS(음성파일)·알림톡 대체 발송
                         └─ DB (배송원·단말·발송 로그), 택배사 운송장 조회 API 연동
```
- 지연 최소화: 사전 녹음 음성(또는 미리 합성해 캐시한 TTS 파일)을 사용하면 통화 응답 즉시 재생 가능
- 개인정보: 앱 화면에서는 전화번호 마스킹, 발신번호는 안심번호(050) 사용 권장

## 2. 화면 구성

| 화면 | 내용 |
|---|---|
| **1. 로그인 / 단말 식별** | 배송원 번호, PIN, 자동 조회된 기기 고유 ID 표시. "고급 설정"에서 알림 서버 주소 입력(비우면 로컬 시뮬레이션). 같은 기기는 다음 실행 시 자동 로그인 |
| **2. 바코드 스캔** | 전체 화면 카메라 뷰파인더, 코너 가이드, 스캔 라인 애니메이션, 플래시 토글. 인식 즉시 진동 후 자동 이동. 카메라가 없을 때를 위한 **운송장번호 직접 입력 / 샘플 송장** 버튼 |
| **3. 수령인 확인** | 운송장번호·수령인·연락처(마스킹, 탭하면 표시)·주소·품목. 배송 위치(문 앞/경비실/무인택배함/직접 전달) 선택 → 음성 문구 자동 생성, 미리듣기. 하단 **「🔊 배송 완료 & 음성 발송」** 원클릭 버튼 |
| **4. 전달 상태 & 로그** | 단계별 타임라인(이벤트 생성 → 서버 접수 → 음성망 발신 → 착신 → 응답·재생 → 완료)과 **각 단계 ms 단위 경과시간**, "탭 → 고객 음성 수신" 지연시간 지표, 발송 로그(탭하여 상세) |

### 지원하는 송장 데이터 형식
| 형식 | 예시 |
|---|---|
| QR (JSON) | `{"inv":"600111222333","name":"홍길동","phone":"010-2345-6789","addr":"…","item":"…"}` |
| 구분자 라벨 | `운송장번호\|이름\|전화\|주소\|품목` |
| key=value | `inv=123456789&name=최고객&tel=01011112222` |
| 숫자 운송장 바코드 (Code128 등) | `600123456789` → 앱 내 모의 운송장 DB에서 수령인 조회 (실서비스에서는 택배사 조회 API) |

### 데모 시나리오용 데이터
- `600123456789` 김민수 — 정상 전달
- `600987654321` 이서연 — 정상 전달
- `600555500000` 박미응답 (전화번호 끝자리 `0000`) — **미응답 → MMS 대체 발송** 시나리오

인쇄/모니터에 띄워 스캔할 라벨 이미지는 [`demo-labels/`](demo-labels/) 폴더에 있습니다.

## 3. 실행 가이드

### 준비물
- PC: Node.js 20 이상
- 스마트폰: **Expo Go** 앱 (Play 스토어 / App Store에서 설치, SDK 58 지원 버전)
- PC와 스마트폰이 **같은 Wi-Fi**에 연결 (회사망 등에서 막히면 아래 `--tunnel` 사용)

### 단계별 실행
```bash
# 1) 의존성 설치
cd delivery-voice-demo
npm install

# 2) 개발 서버 실행
npx expo start
#   같은 Wi-Fi 연결이 안 될 때:  npx expo start --tunnel
```
3. 터미널에 표시되는 QR 코드를
   - **Android**: Expo Go 앱 → "Scan QR code"
   - **iPhone**: 기본 카메라 앱으로 스캔 → Expo Go로 열기
4. 앱이 열리면 `DRV-0001` / PIN `1234` 입력 → **단말기 등록 & 시작**
5. 카메라 권한 허용 → PC 모니터에 `demo-labels/` 이미지를 띄우고 스캔 (또는 "샘플 송장 사용")
6. 수령인 확인 → 배송 위치 선택 → **배송 완료 & 음성 발송** 탭
7. 상태 화면에서 단계별 지연시간 확인, 단말 스피커로 고객이 듣게 될 음성 재생 확인
   - 아이폰은 **무음 스위치가 켜져 있으면 TTS가 들리지 않습니다** — 무음 해제 후 시연
   - Android에서 음성이 안 나오면: 설정 → 텍스트 음성 변환(TTS) → 한국어 음성 데이터 설치

### (선택) 알림 서버 연동 모드
```bash
# 별도 터미널
npm run server
# → "앱 고급 설정에 입력할 주소: http://192.168.x.x:4000" 출력
```
앱 로그인 화면 → "고급 설정" → 위 주소 입력 후 로그인.
- 서버가 단말 등록(배송원 번호 ↔ 기기 ID 바인딩)·토큰 검증을 하고, 다른 기기에서 같은 토큰으로 요청하면 거절합니다.
- 서버 콘솔에 통화 상태 전이가 ms 단위로 출력됩니다. `GET /api/logs` 로 서버측 로그 확인.
- 서버 연결이 실패하면 앱이 자동으로 로컬 시뮬레이션으로 전환하고 타임라인에 그 사실을 표시합니다.

### (선택) 실제 전화로 음성 발송 — Twilio
```bash
TWILIO_ACCOUNT_SID=ACxxxxxxxx \
TWILIO_AUTH_TOKEN=xxxxxxxx \
TWILIO_FROM=+1xxxxxxxxxx \
npm run server
```
- 수령인 번호(010…)는 자동으로 `+8210…` 형식으로 변환되어 발신되고, 통화 연결 시 한국어 TTS(Polly.Seoyeon)로 안내가 2회 재생됩니다.
- Twilio 체험 계정은 **인증된(Verified) 번호로만** 발신 가능하므로, 시연용 휴대폰 번호를 콘솔에서 먼저 인증하세요.
- 국내 상용 서비스에서는 통신사 기업 음성 발신 API 또는 국내 CPaaS로 `twilioCall()` 함수만 교체하면 됩니다.

### 웹 브라우저로 빠른 확인 (선택)
```bash
npx expo install react-dom react-native-web
npx expo start --web
```

### 독립 실행 APK 만들기 (Expo Go 없이 배포)
```bash
npx eas-cli@latest build -p android --profile preview
```

## 4. 파일 구조
```
delivery-voice-demo/
├─ App.js             # 앱 전체 (화면 4종 + 송장 파서 + 음성 전달 엔진)
├─ app.json           # 앱 이름, 카메라 권한 문구 (expo-camera 플러그인)
├─ server/index.js    # 데모 알림 서버 (모의 교환기 / Twilio 실발신)
└─ demo-labels/       # 시연용 QR · 바코드 이미지
```

## 5. 시연 포인트
- **원클릭 즉시성**: 버튼 탭 시점부터 각 단계의 경과시간을 ms 단위로 기록·표시
- **단말 식별**: 배송원 번호와 기기 고유 ID를 바인딩, 서버 모드에서는 다른 기기 요청 차단
- **실패 처리**: 미응답 시 대체 발송 흐름까지 한 화면에서 확인 (`600555500000`)
- 현재 음성 전달은 **시뮬레이션**입니다. 로컬 모드의 단계별 지연시간은 실측값이 아니라 데모용 값이며, 실제 통신망 지연은 Twilio/통신사 연동 모드에서 측정됩니다.
